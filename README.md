# Custom File Encrypter

## Project Overview
Custom File Encrypter is a Java-based mini project developed to demonstrate file encryption and decryption. It aims to help users understand how file contents can be transformed into an encrypted format and restored through decryption.

## Objectives
- Understand file handling in Java.
- Demonstrate basic encryption and decryption concepts.
- Improve awareness of data privacy and file protection.
- Practise Java programming through a practical application.

## Features
- File encryption and decryption.
- File handling using Java.
- Simple and user-friendly workflow.
- Demonstration of basic data protection concepts.
